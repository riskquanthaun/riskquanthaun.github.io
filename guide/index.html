# 블로그 스토리

리스크퀀트하운 블로그

  • 본 블로그에서는 초심자들을 위해 금융 기초지식, QuantLib, 금융공학, 리스크관리 등에 대한 내용을 소개합니다. 금융기관에서 일을 하면서 배운 전문지식들을 간단하게나마 정리하고 소개합니다.

  • RiskQuantHaun 블로그는 VuePress로 작성되었습니다. VuePress는 빠르고 컨텐츠 중심의 웹사이트를 구축하기 위해 설계된 정적 사이트 생성기 (SSG)입니다. 다시말해 VuePress는 마크다운으로 작성된 소스 컨텐츠를 가져와서 테마를 적용하고, 어디에나 쉽게 배포할 수 있는 정적 HTML 페이지를 생성합니다.
