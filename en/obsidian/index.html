# Introducing Obsidian: A Personal Knowledge Management Tool for Organizing and Expanding Your Thoughts

Obsidian Guide | 2025.01.20

Obsidian Overview

In an era where Personal Knowledge Management (PKM) is becoming increasingly important, various note-taking apps are emerging. Among them, Obsidian stands out as a connection-based note-taking tool.

Obsidian is a cross-platform note-taking app that allows you to write using Markdown syntax. Unlike cloud-based note apps, Obsidian stores files locally, eliminating concerns about data loss if the service is discontinued. It can also be used offline without requiring an internet connection.

# Obsidian: A Tool to Help Organize and Expand Your Thoughts

Obsidian is a local file-based Markdown note-taking app. All notes created by the user are saved as Markdown files in local folders, ensuring excellent data ownership and security. It also offers a Graph View that allows users to build a knowledge network through linking between notes and visually understand the relationships between them. This connection-focused structure is effective not only for organizing notes but also for expanding thoughts and building deep knowledge.

For example, while note-taking apps like Evernote or Notion may struggle with managing an increasing number of notes due to a lack of linking concepts, Obsidian provides features such as note linking, tags, and a visual graph view to systematically organize and connect information. These features help users easily navigate complex ideas and information, recognize relationships among them, and think from new perspectives.

Although other note apps like Roam Research, Upnote, and Logseq offer similar concepts, Obsidian stands out with its customizable flexibility, local file-based data management, and a rich plugin ecosystem.

# Exploring the History and Pricing Plans of Obsidian

Obsidian was launched in 2020 by two developers, Shida Li and Erica Xu. They aimed to create a connection-based knowledge management tool that existing note apps could not provide.

Since its launch, Obsidian has rapidly expanded its features by reflecting diverse user feedback and has gained significant popularity, especially among developers and professional communities. Currently, it is available for free for personal use and also offers paid plans for teams and businesses.

# Key Features of Obsidian

Manifesto on Obsidian's Core Principles (opens new window)

Key features of Obsidian include: Markdown-based writing, Local data storage, Bidirectional linking, Graph view, Plugin extensibility, Multi-platform support

Markdown-Based Writing

  • You can quickly and efficiently take notes using the simple and intuitive Markdown syntax. Even without the Obsidian app, documents can be read and edited anywhere with any text editor, making migration to other note-taking platforms exceptionally easy.
  • Additionally, since Markdown is purely text-based, Obsidian offers faster performance than any WYSIWYG note-taking app.

Local Data Storage

  • Since all notes are stored locally, you can use Obsidian without an internet connection, ensuring high security for personal data. It operates locally, eliminating the need for an internet connection or separate cloud storage, and there are no policy-imposed limits on the number of documents or storage capacity.

Bidirectional Linking

  • Notes can be mutually linked, allowing users to easily find related information and expand the context of their knowledge.

Graph View

  • It visually displays the connections between notes, enabling users to understand their knowledge network at a glance. This feature allows users to easily create mind maps and diagrams based on their documents.
  • In other words, it supports both markup-based document editing and efficient visualization.

Plugin Extensibility

  • Users can freely expand Obsidian's functionality through numerous official and community plugins. Examples include calendars, task managers, and PDF viewers.
  • Essential features are already available as core plugins. Common tools like the file explorer tab, search function, graph view, and backlinks are all built-in plugins. There’s no need to search for similar community plugins, and if you prefer a lightweight setup, you can disable any unused core plugins.

Multi-Platform Support

  • Obsidian is available on Windows, macOS, Linux, and even mobile apps for Android and iOS, allowing you to write and manage notes anytime, anywhere. Additionally, with the paid feature Obsidian Sync (cross-device note synchronization), real-time synchronization across platforms is possible.

# Advantages of Obsidian

The advantages of Obsidian include: Data ownership and security, Flexible customization, Powerful connectivity, Fast performance and stability

Data Ownership and Security

  • By using local file storage instead of cloud-based systems, users have complete ownership of their data.

Flexible Customization

  • The app can be customized freely with various plugins and CSS themes.

Powerful Connectivity

  • Bidirectional links and Graph View enable intuitive understanding of relationships between information.

Speed and Stability

  • Thanks to its local storage and lightweight Markdown files, Obsidian offers fast and stable performance.

# Disadvantages of Obsidian

The disadvantages of Obsidian include: Somewhat complex for beginners, Limitations of basic features, Limitations of the mobile app, Lack of built-in automatic synchronization

Complexity for Beginners

  • Markdown syntax, link structures, and plugin installations can present a learning curve for first-time users.

Limitations of Basic Features

  • In its default state, features are simple, making plugin installation essential for expansion. Due to its Markdown-based design, functional limitations are inevitable.

Limitations of the Mobile App

  • Compared to the desktop version, the mobile app has restricted functionality and lower plugin compatibility.

No Automatic Sync Support

  • Obsidian does not have built-in cloud sync. Users must use separate tools (e.g., Dropbox, iCloud, Syncthing). Its lack of real-time collaboration features means it doesn't support key functions like highlighted comments, document-specific editing permissions, review requests, voting, or document monitoring.

# Who Is Obsidian Best For?

Obsidian is a powerful yet flexible note-taking tool suitable for users who prioritize organizing and managing information. It is especially valuable in the following situations:

When Mental Clarity Is Needed

  • If life feels overwhelming, Obsidian helps systematically organize thoughts and store important ideas.

For Improving Memory

  • Obsidian can prevent forgetting important information or tasks and reduce the stress of trying to remember everything.

For Those Who Enjoy Journaling and Writing

  • Obsidian is a powerful tool for recording personal thoughts and experiences, providing space for creative writing and deep reflection.

For Readers, Writers, and Researchers

  • When exploring knowledge and new ideas, Obsidian is essential for organizing and connecting important materials and insights.

For Those Who Struggled with Previous Note-Taking Methods

  • Users who found traditional note-taking ineffective can discover better knowledge management through Obsidian's flexible and connected note system.

# Tips for Using Obsidian

Utilize Various Views and Maps

  • Use different views (e.g., file explorer, graph view) to visually understand the structure and connections of information.
  • Create maps (e.g., Maps of Content - MOCs) that visually show note connections to better understand and manage information flow.

Dashboard Setup

  • Set up a 'dashboard' in Obsidian for quick access to frequently referenced or important information.
  • Include links and summaries of key notes in the dashboard.

Gradual Expansion

  • Don't aim to organize everything perfectly from the start; gradually expand notes and structures over time.
  • Adjust notes and add new connections as thoughts and ideas develop.

Plugins and Advanced Features

  • Use plugins like Dataview and Templater to expand Obsidian’s functionality.
  • These plugins offer advanced features such as data management, automation, and custom template creation.

Strategic Information Storage and Backup

  • Store notes efficiently by recording only necessary information.
  • Regularly back up notes to ensure data security.

# Conclusion

A Powerful Tool for Productivity and Knowledge Management

  • Obsidian is more than just a note-taking app; it’s a powerful tool focused on connection-based knowledge management.
  • It is optimized for expanding personal thinking and building a deep knowledge network through information linking and visualization.
  • The freedom of Markdown-based writing and plugin extensibility allows users to create personalized workflows. However, it may feel complex for beginners, so gradually learning its features is recommended.
  • If you value productivity and knowledge management, trying out Obsidian is highly recommended.
