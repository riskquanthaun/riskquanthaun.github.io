# QuantLib-Python: Examples

QuantLib Guide | 2025.01.12

QuantLib Python

  • QuantLib is a powerful open-source library for quantitative financial analysis and financial product pricing and analysis.

  • QuantLib is widely used in the financial industry for tasks such as derivative pricing, risk management, and financial product modeling.

  • While QuantLib itself is written in C++, it also provides Python bindings, making it accessible to Python developers.

  • Through QuantLib-Python, you can easily use QuantLib with Python syntax.

# Understanding QuantLib's Design Structure

Let's first look at the overall framework of QuantLib.

# Component #1: Derivatives

Derivative Objects: Instrument Class

  • QuantLib is a tool for easily pricing derivatives. It has an object-oriented structure, meaning everything is an object.
  • Since QuantLib is a tool for pricing derivatives, the most important object in QuantLib must be the derivative itself.
  • In QuantLib, these derivatives are managed collectively in the Instrument Class. Individual derivative objects can be implemented through the subclasses of this Instrument Class.

# Component #2: Pricing Engine

Pricing Engine Object: PricingEngine Class

  • The subject of derivative pricing is the derivative object. The next question is how to price the derivative.
  • A tool for derivative pricing is needed, and in QuantLib, this pricing tool is implemented as the PricingEngine Class.
  • The PricingEngine class can also determine how to price through its subclasses.

# Component #3: Underlying Assets

Underlying Asset Objects: Quote Class, TermStructure Class

  • By definition, a derivative financial product's price is inevitably affected by changes in the underlying asset, so implementing the underlying asset is essential when implementing derivative valuation.
  • To implement underlying asset objects, QuantLib has the Quote Class and TermStructure Class.

# Performing Price Evaluation

For QuantLib to function properly, these three objects are needed: derivative, pricing engine, and underlying asset. Without any one of these main objects, QuantLib cannot perform pricing normally.

QuantLib performs pricing by passing information about the underlying asset to the pricing engine and then passing this pricing engine to the derivative.

  • Underlying Asset --> Pricing Engine --> Derivative --> Pricing Result

# QuantLib-Python Modules

QuantLib-Python consists of various modules, each focusing on specific aspects of financial engineering.

# Date Class

  • Date-related calculations are very important in derivative valuation. This module includes classes and functions for managing dates, day calculations, and day counting rules.

    import QuantLib as ql

# Create a Date object for December 1st, 2024
date = ql.Date(1, 12, 2024)

# Get today's date
today = ql.Date.todaysDate()

# Add 30 days to the date
future_date = date + ql.Period(30, ql.Days)
print(f"Future Date: {future_date}")

# Calendar Class

  • This module handles financial calendars essential for calculating dates related to financial products. It includes various classes for financial calendars, holidays, and business day conventions.

    import QuantLib as ql

# Get a US calendar
us_calendar = ql.UnitedStates()

# Check if a given date is a business day
date = ql.Date(1, 1, 2024)
is_business_day = us_calendar.isBusinessDay(date)
print(f"Is business day: {is_business_day}")

# PricingEngines Class

  • This module includes pricing engines for various types of financial products such as options, bonds, and swaps. These engines are used to calculate the fair value of these products.

# Instruments Class

  • Here you can find classes representing various financial instruments, including options (e.g., European options), bonds (e.g., fixed-rate bonds), and swaps (e.g., interest rate swaps).

# Currencies Class

  • This module provides classes that can work with various currencies, including currency codes, exchange rates, and conversion functions.

# MarketData Class

  • This module handles market data such as interest rates, yield curves, and volatility surfaces. It provides tools to manage and interpolate market data.

# Solvers Class

  • Solvers are used to find solutions to various mathematical problems such as root finding and optimization. This module provides tools for solving financial equations.

# Pricing Example Code

To use QuantLib in Python, you typically need to start by importing the necessary modules and classes. This allows you to create financial instruments, set up pricing engines, and perform calculations according to specific requirements.

The following examples show simple methods for calculating financial product evaluation prices using QuantLib in Python.

# Term Structures (Yield Curves)

import QuantLib as ql

# Define the discounting curve using a flat forward model
today = ql.Date(13, 10, 2024)
ql.Settings.instance().evaluationDate = today

rate = ql.SimpleQuote(0.05)
discount_curve = ql.FlatForward(today, ql.QuoteHandle(rate), ql.Actual360())

# Get discount factor for a future date
future_date = ql.Date(13, 10, 2025)
discount_factor = discount_curve.discount(future_date)
print(f"Discount Factor: {discount_factor}")

# Pricing a European Call Option

import QuantLib as ql

# Set Date
valuationDate = ql.Date(28, 8, 2024)
ql.Settings.instance().evaluationDate = valuationDate
calendar = ql.NullCalendar()
dayCount = ql.Actual360()

# Define Option Parameters
option_type = ql.Option.Call
underlying_price = 100
strike_price = 105
maturity_date = ql.Date(15, 9, 2025)
volatility = 0.2
risk_free_rate = 0.05
dividend = 0.01

# Simple Quote Objects
underlying_qt = ql.SimpleQuote(underlying_price)
dividend_qt = ql.SimpleQuote(dividend)
risk_free_rate_qt = ql.SimpleQuote(risk_free_rate)
volatility_qt = ql.SimpleQuote(volatility)

# Quote Handle Objects
u_qhd = ql.QuoteHandle(underlying_qt)
d_qhd = ql.QuoteHandle(dividend_qt)
r_qhd = ql.QuoteHandle(risk_free_rate_qt)
v_qhd = ql.QuoteHandle(volatility_qt)

# Term-Structure Objects
d_ts = ql.FlatForward(valuationDate, d_qhd, dayCount)
r_ts = ql.FlatForward(valuationDate, r_qhd, dayCount)
v_ts = ql.BlackConstantVol(valuationDate, calendar, v_qhd, dayCount)

# Term-Structure Handle Objects
d_thd = ql.YieldTermStructureHandle(d_ts)
r_thd = ql.YieldTermStructureHandle(r_ts)
v_thd = ql.BlackVolTermStructureHandle(v_ts)

# Process & Engine
process = ql.BlackScholesMertonProcess(u_qhd, d_thd, r_thd, v_thd)
engine = ql.AnalyticEuropeanEngine(process)

# Option Objects
exercise = ql.EuropeanExercise(maturity_date)
payoff = ql.PlainVanillaPayoff(option_type, strike_price)
option = ql.VanillaOption(payoff, exercise)

# Set the pricing engine for the option
option.setPricingEngine(engine)

# Price & Greeks Results
print("Option Price:", round(option.NPV(), 2))
print("Option Delta:", round(option.delta(), 4))
print("Option Gamma:", round(option.gamma(), 4))
print("Option Theta:", round(option.thetaPerDay(), 4))
print("Option Vega:", round(option.vega() / 100, 4))
print("Option Rho:", round(option.rho() / 100, 4))

# Automatic Re-Pricing
underlying_qt.setValue(103)
print("\n# Automatic Re-Pricing")
print("Option Price:", round(option.NPV(), 2))
print("Option Delta:", round(option.delta(), 4))
print("Option Gamma:", round(option.gamma(), 4))
print("Option Theta:", round(option.thetaPerDay(), 4))
print("Option Vega:", round(option.vega() / 100, 4))
print("Option Rho:", round(option.rho() / 100, 4))

# Pricing a Fixed Income Bond

import QuantLib as ql

# Define bond parametes
face_value = 100
issue_date = ql.Date(15, 9, 2021)
maturity_date = ql.Date(15, 9, 2031)
coupon_rate = 0.05
settlement_date = ql.Date(15, 9, 2023)

# Create QuantLib objects
schedule = ql.MakeSchedule(issue_date, maturity_date, ql.Period('6M'))
interest = ql.FixedRateLeg(schedule, ql.Actual360(), [100.], [0.05])
bond = ql.Bond(0, ql.TARGET(), issue_date, interest)

# Set Pricing Engine
crv = ql.FlatForward(settlement_date, coupon_rate, ql.Actual360())
yts = ql.YieldTermStructureHandle(crv)
engine = ql.DiscountingBondEngine(yts)
bond.setPricingEngine(engine)

# Calculate bond price
bond_price = bond.cleanPrice()
print("Fixed Income Bond Price:", round(bond_price, 4))

## Fixed Income Bond Price: 99.6176
