# QuantLib-Python: Period Class

QuantLib Guide | 2025.01.16

Period Class

  • The QuantLib Period class is used to represent time periods and is an important class for defining intervals between dates.

  • The Period class is primarily used to define periods such as financial product maturities and interest payment intervals.

  • While the Date class exists to define specific dates, the Period class exists to define specific periods and intervals between points in time.

# Period Class Overview

All derivatives fundamentally require various date information such as effective date, maturity date, settlement date, and interest payment date. These details are not only basic elements that constitute a derivative, but since the product price can vary depending on how these details are defined, these details are very precisely documented in the term sheet for trading derivatives.

The reason such date information is needed is essentially to determine how long until a product's maturity or how long until the next interest payment date. In other words, for pricing or position management, what we need to focus on is not the date but the period. This means that relative intervals are more important than absolute points in time, and our perspective should focus on lines rather than points.

# Period Class Structure

While the Date class exists to define specific dates, the Period class exists to define specific periods. The Period class is not meant to define exact points in time but rather to determine the duration between points in time. To use the Period class, you need to follow this structure:

# Period Class Implementation Method #1

import QuantLib as ql

# ql.Period(Integer, TimeUnits)
period = ql.Period(3, ql.Months)  # 3M
print(period.length())  # 3
print(period.units())   # Months
  • The first method is to set an Integer and TimeUnits as arguments.
  • For integers, you can input regular numbers, but what needs attention here is time. QuantLib has various enumerations for different purposes.
  • An Enumeration refers to a data type that forms a set composed of a series of members, where specific enumerations are like groups organized by users for specific purposes. Time units are one such enumeration with the following members.
  • For example, if you want to define a period of 3 months, enter 3 as the first argument and ql.Months as the second argument.

TimeUnits

  • ql.Days
  • ql.Weeks
  • ql.Months
  • ql.Years

# Period Class Implementation Method #2

import QuantLib as ql

# ql.Period(Frequency)
period = ql.Period(ql.Semiannual)
print(period)  # 6M
  • The second way to define the Period class is to input a Frequency as an argument.
  • In QuantLib, frequency is also created as an enumeration, and below are the members that make up the frequency enumeration.
  • This frequency enumeration is commonly used in implementing products such as interest rate swaps or currency swaps that pay interest at specific intervals.

Frequency

  • ql.Annual
  • ql.Semiannual
  • ql.Quarterly
  • ql.Monthly
  • ql.Biweekly
  • ql.Daily
  • ql.Once

# Period Class Functions

The main feature of the Period class is that it enables arithmetic operations on dates when combined with the Date class. For example, let's say we want to know the date 3 weeks, 3 months, or 3 years after April 10, 2024.

When combining the Date class with the Period class, we can easily answer such questions. This ability to add and subtract specific periods to dates is one of QuantLib's useful features. Such arithmetic calculations are also possible between dates, providing answers about the duration between two dates.

# Functions
import QuantLib as ql

date1 = ql.Date(10, 4, 2024)
date2 = ql.Date(31, 12, 2024)

print(f"After 3 Weeks : {date1 + ql.Period(3, ql.Weeks)}")
print(f"After 3 Months : {date1 + ql.Period(3, ql.Months)}") 
print(f"After 3 Years : {date1 + ql.Period(3, ql.Years)}")

print(f"Days between Date2 and Date1 = {date2 - date1}")

## OutPut
## After 3 Weeks : May 1st, 2024   
## After 3 Months : July 10th, 2024
## After 3 Years : April 10th, 2027
## Days between Date2 and Date1 = 265
