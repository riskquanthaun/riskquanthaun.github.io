# QuantLib-Python: InterestRate Class

QuantLib Guide | 2025.01.26

InterestRate Class

  • The InterestRate class calculates exact interest rates, discount factors, and compound factors for specific periods based on given market conventions.

  • Interest rates must specify the specific period to which they apply, and this characteristic of interest rates requires discussion of holiday handling, day count conventions, and interest compounding methods.

# InterestRate Class Overview

FICC stands for Fixed Income, Currency, and Commodity. Here, Fixed Income refers to interest rate-related assets. An interest rate refers to the additional compensation that must be paid or received when borrowing or lending money for a certain period. However, interest rates have different characteristics from other underlying assets like stock prices, exchange rates, and commodity prices. Specifically, interest rates are a concept of period rather than a point in time.

Interest rates must explicitly specify the specific period to which they apply, not just a point in time. Furthermore, this characteristic of interest rates requires discussion of holiday handling, day count conventions, and interest compounding methods. Due to these unique characteristics of interest rates, QuantLib has created a separate InterestRate class distinct from other underlying assets.

# InterestRate Class Structure

The InterestRate class calculates exact interest rates, discount factors, and compound factors for specific periods based on given market conventions.

# InterestRate Class Definition

Four parameters are needed to define this class: rate, day count convention (DayCounter), compounding method (Compounding), and payment frequency (Frequency).

import QuantLib as ql

# ql.InterestRate(rate: Real, 
#                 dayCount: ql.DayCounter,
#                 compounding: ql.Compounding,
#                 frequency: ql.Frequency)
rate = ql.InterestRate(0.05, 
                       ql.Actual360(), 
                       ql.Compounded, 
                       ql.Annual)

# Compounding Enumeration

Compounding is an enumeration consisting of members that determine how to calculate compound interest. This enumeration has five sub-members as follows:

In the actual financial world, most interest calculations use regular compound interest. However, when modeling in financial engineering, interest rate models assume continuous compounding.

Compounding

  • ql.Simple: Simple interest [c = 1 + rt]
  • ql.Compounded: Compound interest [c = (1 + r/f)^(tf)]
  • ql.Continuous: Continuous compounding [c = e^(rt)]
  • ql.SimpleThenCompounded: Simple interest until next coupon date, then compound
  • ql.CompoundedThenSimple: Compound interest until next coupon date, then simple
    • c: compound factor
    • r: interest rate
    • t: maturity
    • f: annual payment frequency

# Conventional Compound Discount Method

Conventional Compound Discount Method

  • The actual method for calculating Korean bond prices is a conventional compound discount method, similar to the fourth ql.SimpleThenCompounded method above.
  • However, the Korean bond valuation convention differs from QuantLib's ql.SimpleThenCompounded method.
  • This is because it reflects actual days in calculating the compound factor until the next coupon date.
  • Korean bond valuation convention can be found in the Korea Financial Investment Association > Regulations on Business and Operations of Financial Investment Companies (opens new window) > [Appendix 14: Bond Yield Price Conversion Formula].
  • A modified InterestRate class reflecting Korean bond valuation conventions is attached at the bottom.

# InterestRate Class Functions

# Discount Factor and Compound Factor Calculation

InterestRate Class Functions

  • discountFactor(d1, d2) method: Calculate discount factor for a specific period
  • compoundFactor(d1, d2) method: Calculate compound factor for a specific period
import QuantLib as ql

rate = ql.InterestRate(0.05, ql.Actual360(), ql.Compounded, ql.Annual)

# Discount Factor & Compound Factor
print("Rate: ", rate.rate())
print("DayCount: ", rate.dayCounter())
print("DiscountFactor: ", rate.discountFactor(1))
print("DiscountFactor: ", rate.discountFactor(ql.Date(15,6,2020), ql.Date(15,6,2021)))
print("CompoundFactor: ", rate.compoundFactor(ql.Date(15,6,2020), ql.Date(15,6,2021)))

# Output
# Rate:  0.05
# DayCount:  Actual/360 day counter
# DiscountFactor:  0.9523809523809523
# DiscountFactor:  0.9517357984551467
# CompoundFactor:  1.050711764360651

# Interest Rate Calculation Under Different Market Conventions

equivalentRate(resultDC, comp, freq, d1, d2)

  • Returns an equivalent interest rate under different conditions
  • Day count convention (resultDC), compounding method (comp), payment frequency (freq), start date (d1), end date (d2)

impliedRate(compound, resultDC, comp, freq, d1, d2)

  • When given a compound factor, returns the implied interest rate by reverse calculation
  • Compound factor (compound), day count convention (resultDC), compounding method (comp), payment frequency (freq), start date (d1), end date (d2)
import QuantLib as ql

rate = ql.InterestRate(0.05, ql.Actual360(), ql.Compounded, ql.Annual)

print("Rate: ", rate.rate())
print("DayCount: ", rate.dayCounter())

print("EquivalentRate: ", rate.equivalentRate(ql.Actual360(),       # resultDC
                                              ql.Compounded,        # comp
                                              ql.Semiannual,        # freq
                                              ql.Date(15,6,2020),   # d1
                                              ql.Date(15,6,2021)))  # d2

factor = rate.compoundFactor(ql.Date(15,6,2020), ql.Date(15,6,2021))
print("ImpliedRate: ", rate.impliedRate(factor,                # compound
                                        ql.Actual360(),        # resultDC     
                                        ql.Continuous,         # comp
                                        ql.Annual,             # freq
                                        ql.Date(15,6,2020),    # d1
                                        ql.Date(15,6,2021)))   # d2

# Output
# Rate:  0.05
# DayCount:  Actual/360 day counter
# EquivalentRate:  4.939015 % Actual/360 Semiannual compounding
# ImpliedRate:  4.879016 % Actual/360 continuous compounding

# Korean Conventional Compound Discount Implementation: InterestRate Class

Conventional Compound Discount Method

  • The actual method for calculating Korean bond prices is a conventional compound discount method, similar to the fourth ql.SimpleThenCompounded method above.
  • However, the Korean bond valuation convention differs from QuantLib's ql.SimpleThenCompounded method.
  • This is because it reflects actual days in calculating the compound factor until the next coupon date.
  • Korean bond valuation convention can be found in the Korea Financial Investment Association > Regulations on Business and Operations of Financial Investment Companies (opens new window) > [Appendix 14: Bond Yield Price Conversion Formula].

A modified InterestRate class reflecting Korean bond valuation conventions is attached at the bottom.

class InterestRate(ql.InterestRate):
    """Modify QuantLib InterestRate Class
       SimpleThenCompounded in QuantLib is not Korea Treasury Compounding Convention
       if compounding == ql.SimpleThenCompounded:
           for t <= 1/f : c = 1 + r*t
           for t > 1/f  : c = (1 + r/f)^(tf)
           where t = days / first_period_days
    """
    def __init__(self, r, dc, comp, freq):
        super().__init__(r, dc, comp, freq)
        self._r = r
        self._dc = dc
        self._comp = comp
        self._freq = freq.real
    
    def discountFactor(self, d1, d2):
        r = self._r
        dc = self._dc
        comp = self._comp
        freq = self._freq
        t = dc.yearFraction(d1, d2)
        if comp == ql.SimpleThenCompounded:
            n = int(np.divmod(t, 1/freq)[0])
            nextDate = d2 - ql.Period(int(n*12/freq), ql.Months)
            prevDate = d2 - ql.Period(int(n*12/freq + 12/freq), ql.Months)
            if (t <= 1.0/freq):
                df = 1 / (1.0 + r/freq * (nextDate-d1) / (nextDate-prevDate))
            else:
                df = 1 / ((1.0 + r/freq * (nextDate-d1) / (nextDate-prevDate)) * ((1 + r/freq)**n))
        else:
            df = super().discountFactor(d1, d2)
        return df
    
    def compoundFactor(self, d1, d2):
        r = self._r
        dc = self._dc
        comp = self._comp
        freq = self._freq
        t = dc.yearFraction(d1, d2)
        if comp == ql.SimpleThenCompounded:
            n = int(np.divmod(t, 1/freq)[0])
            nextDate = d2 - ql.Period(int(n*12/freq), ql.Months)
            prevDate = d2 - ql.Period(int(n*12/freq + 12/freq), ql.Months)
            if (t <= 1.0/freq):
                df = 1.0 + r/freq * (nextDate-d1) / (nextDate-prevDate)
            else:
                df = (1.0 + r/freq * (nextDate-d1) / (nextDate-prevDate)) * ((1 + r/freq)**n)
        else:
            df = super().compoundFactor(d1, d2)
        return df
